# University of Sindh Alumni

Project repository for the University of Sindh Alumni platform.

## Governance

- Ghulam Mallah is the owner and final approval authority.
- Development work should use branches and pull requests.
- Do not merge to `main` or deploy to production without Ghulam's approval.
- Do not store passwords, API keys, tokens, private alumni data or production credentials in GitHub.
- Use synthetic or sanitised data for development and testing.
- Use normal ASCII punctuation. Do not use em dash or en dash characters.
